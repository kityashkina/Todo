# Todo

WPF приложение для управления задачами.

## Начало работы

Эти инструкции помогут вам запустить проект на локальном компьютере для разработки и тестирования.

### Необходимые условия

Что нужно установить перед началом работы:
- Visual Studio 2022 или новее
- .NET 6.0 или выше
- Git

### Установка

Пошаговая инструкция по запуску проекта:

1. Откройте Visual Studio
2. Выберите "Клонировать репозиторий"
3. Вставьте URL репозитория: https://github.com/kityashkina/Todo
4. После завершения клонирования перейдите на ветку "lab4"
5. Запустите проект нажатием F5 или кнопки "Start"
